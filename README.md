Code Trap

Code Trap is a number-guessing game developed in C using the raylib library.

Your goal is to crack a secret four-digit code before running out of attempts.

How to Play

Guess the secret four-digit code.

Each digit must be unique.

The first digit cannot be zero.

You have 8 attempts to crack the code.

Use the feedback after each valid guess to improve your next attempt.

Controls

ENTER — Start the game, submit a guess, or play again.

BACKSPACE — Delete the last digit.

ESC — Exit the game.
